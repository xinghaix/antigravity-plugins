# MCP Manager (`mcp-manager`)

This plugin provides the **MCP Manager** visual UI panel in the auxiliary pane for managing global (`~/.gemini/config/mcp_config.json`), workspace (`.agents/mcp_config.json`), and plugin MCP servers.

When the user wants to open or use the visual MCP manager, surface the sidecar pill link:

[MCP Manager](sidecar://mcp-manager/mcp_manager/)

You can also help the user inspect, add, edit, toggle, or troubleshoot MCP server entries in `~/.gemini/config/mcp_config.json` and `<workspace>/.agents/mcp_config.json`.
