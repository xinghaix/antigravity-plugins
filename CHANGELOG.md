# Changelog

All notable changes to the `antigravity-plugins` monorepo will be documented in this file.

## [Unreleased]

### Changed
- Synced `antigravity-context-viewer` to upstream `v0.8.8` (`0.8.8-1`) and strengthened **Google Antigravity `2.33+` compatibility**:
  - Merged all `v0.8.8` features (`meter-accounts.js` multi-account ledger isolation & opt-in quota-pool switching, `macos-binary-utils.js` Apple Silicon `arm64` `fixed`/`dynamic`/`default` context unlock + enhance, `runtime-check.js`, per-model stacked daily usage bars with `.db` model backfill, redesigned cumulative view & hybrid log-power scale, collapsible request timeline with `elv91-v1` speed scoring, `watch`/`stop-watch` daemon mode, WSL log collection, trilingual `zh-CN`/`zh-TW`/`en` currency formatting & custom datepicker).
  - Updated `local-api.js` and `cli.js` with `~/.gemini/antigravity/daemon/hub_*.json` Language Server discovery (checking PID liveness and preferring `httpsPort` before `httpPort` and `main.log`) so `2.33+` no-CDP sessions connect live out of the box.
  - Updated `sidecars/live-loader/ui-server.js` (`sanitizeUnlockPayload` reading `configuredMode`/`configuredLimitTokens`), preserved all custom features (Aux Pane Sidecar UI, `2.33` selectors, auxiliary HUD skip, monochrome dual-ring badge styling, default-hidden CLI toggle, `sidecarChinese` live i18n), and kept prompt/title rewrite options strictly **OFF** by default.
- Upgraded `antigravity-context-viewer` to `0.8.7-2` for **Google Antigravity `2.33.0+` compatibility**:
  - Added a native Aux Pane Web UI (`sidecars/live-loader/ui-server.js`, `index.html`, `styles.css`, `app.js`, `has_web_ui: true`) powered by `sidecar_sdk`, displaying live session context, quota pools, token history, diagnostics, and settings even when CDP (`DevToolsActivePort`) is disabled by default in Antigravity `2.33+`.
  - Updated `local-api.js` with `main.log` Language Server origin discovery fallback when `DevToolsActivePort` is absent; fixed `meter-collector.js` `collect()` `ReferenceError: cachedHostUserStatus is not defined`; fixed `meter-context-unlock.js` macOS/Unix process detection (`ps -ax -o pid=,etime=,command=` + executable path match) so restarted `language_server` resolves to `patched_loaded` cleanly; updated `cli.js` (`cdp_disabled` detection + `launch [--port N] [--restart]` command) and `sidecar-live.js` (relative manifest path check, `cdp_disabled` handling, parallel Web UI startup); updated `src/renderer/main.js` and `meter-main.js` for Antigravity `2.33` aux-pane selectors and aux HUD window filtering.
- Synced `antigravity-context-viewer` to upstream `v0.8.7` (`0.8.7-1`, including `v0.8.6` and `v0.8.7`): adopted upgraded CDP & in-app hot-reload pipeline (preserving drafts, expanded drawers, and scroll positions), multi-window origin isolation, `callBackendWithPriority`, DPI pixel-grid snapping, download retry diagnostics, and truncation-guard build script, while ensuring all prompt/title modification options default to **OFF** (`promptTier: null`, `chineseTitle: null`, `#chk-rec-prompt` / `#chk-rec-title` unchecked by default) and preserving all custom features (Sidecar auto-loader, Ultra `5x`/`20x` sub-tier detection, unified topbar styling, CLI visibility toggle, and macOS `arm64` context unlock).
- Upgraded `antigravity-context-viewer` to `0.8.5-3`: added automatic Google AI Ultra `5x` (`g1-ultra-lite-tier`, `$99.99/mo`) and `20x` (`g1-ultra-tier`, `$199.99/mo`) sub-tier detection with dynamic CNY conversion and cached plan upgrades, unified topbar `#badge-quota` visual styling (`○ 22% · 5h`) with our monochrome `#badge` (`○ 261K · 33%`) purely via CSS for clean upstream compatibility, and improved responsive toolbar coexistence with sibling UI plugins.
- Upgraded `antigravity-context-viewer` to `0.8.5-2`: fixed Google AI Ultra/Plus false-positive `no_permission` (`无权限`) quota status (`teamsTier` passthrough, tier-hierarchy `allowedTiers` matching, server-granted quota trust), filtered decorative tags (`New`, `Beta`, `Preview`, etc.) from unavailability reasons and notices, and added live renderer quota reconciliation plus Sidecar managed-bridge module reload on bundle update.
- Added single-plugin release packaging & workflow support (`<plugin-id>-v<version>` tags, `npm run pack:release -- --plugin <plugin-id>`) so only updated plugins are published individually.
- Upgraded `antigravity-context-viewer` from `0.8.2` to `0.8.5-1` (adopting `<upstream-version>-<rev>` versioning to track upstream `elviscjn-cjn/antigravity-context-viewer` `v0.8.5`), bringing model quota rings, per-model context budgets, System Enhancement Hub, Gemini 4 Hydrogen pricing, background ledger workers, and `v0.8.5` stability fixes while preserving native Sidecar CDP auto-loading, macOS `arm64` Mach-O context unlock (`codesign`), and custom top-bar UX.

## [1.0.0] - 2026-11-13

### Added
- Initial monorepo release consolidating `mcp-manager` (`v1.0.0`), `mattpocock-skills` (`v1.0.0`), and the modified `antigravity-context-viewer` (`v0.8.2`, derived from `elviscjn-cjn/antigravity-context-viewer`) under `plugins/` with unified MIT licensing.
- Root `AGENTS.md`, `registry.json` auto-sync (`scripts/sync-registry.mjs`), and bilingual storefront docs (`README.md`, `README.en.md`).
- Unified CLI (`scripts/cli.mjs`) supporting selective or full `--link` / `--copy` install, uninstall, `list`, `status`, and `doctor`, plus remote single-plugin `install.sh` (per-plugin release tarball or sparse git checkout).
- Plugin scaffolding generator (`scripts/new-plugin.mjs`) with optional Sidecar Aux Pane UI boilerplate (`--ui`).
- Unified quality & release pipeline (`scripts/check-all.mjs`, `scripts/test-all.mjs`, `scripts/package-release.mjs`) producing per-plugin archives (`<id>.tar.gz`, `<id>.zip`) and full monorepo bundles.
- Cross-platform GitHub Actions CI (`ubuntu-latest`, `macos-latest`, `windows-latest`), Release automation, and upstream `mattpocock/skills` sync workflow.
